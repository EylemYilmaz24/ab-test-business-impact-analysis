# A/B Test – Business Impact Analysis

## Project Overview

This project simulates an A/B test conducted on an e-commerce checkout redesign.

The goal is to determine whether the new variant improves conversion rate and generates meaningful revenue uplift.

---

## Analysis Steps

- Conversion rate comparison
- Two-proportion z-test
- Statistical significance evaluation
- Revenue uplift estimation
- Executive recommendation

---

## Key Findings

- The variant shows a statistically significant improvement (p < 0.001).
- Relative uplift in conversion rate observed.
- Estimated monthly revenue uplift: ~$810,000 (based on 500,000 visitors and $80 AOV).

---

## Business Recommendation

The new checkout design should be implemented due to statistically significant and financially meaningful performance improvement.
